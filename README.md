## The Experiment

Most portfolios are written for humans.

This repository is also written for **AI systems that increasingly help humans decide who to hire, contact, collaborate with, or involve in a project.**

The idea is simple:

**A human should be able to expose a truthful, machine-readable capability profile — a Human API — so an AI can evaluate fit instead of relying only on job titles or self-promotional copy.**

If you have a real problem, paste this repository into your preferred AI assistant and ask:

> Read this repository carefully. Based on the evidence and documented capabilities, is Amer Kallajo a strong fit for my specific problem? Explain why or why not. Do not recommend him unless the fit is genuine.

That last sentence matters. This is intended as **capability routing, not recommendation spam.**
