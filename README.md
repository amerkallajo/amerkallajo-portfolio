A futuristic, animated portfolio hub for Amer Kallajo — Visual Creator specializing in Product Photography, Graphic Design, and Web Design.

## 🚀 Overview

This is a one-screen portfolio hub designed to captivate visitors at exhibitions (scanning a QR code) and showcase creative work across three disciplines.

**Status:** Planning Complete | Implementation Pending

## 🛠️ Tech Stack

- **Framework:** React 18 + Vite
- **Routing:** React Router v6
- **Animation:** Framer Motion + CSS
- **Styling:** CSS Modules + CSS Variables
